# Descrição da avaliação Cantina

#### API desenvolvida com Java, Spring Boot e MySQL no site Spring Initializr, para o gerenciar uma cantina escolar


### Possui os endpoints:

Get     |   Consulta um lanche

Put     |   Atualiza um Lanche

Delete  |   Remove um lanche

Get     |   Lista os lanches

Post    |   Cadastra um lanche

### Objetivo

Substituir a manutenção manual do cardápio (feita diretamente no código) 
por uma API que permite cadastrar, listar, consultar, atualizar e remover lanches de forma dinâmica.


### Observações

Foi feito o teste e o programa rodou normalmente, porém não consegui implementar os Exceptions na aplicação.
Na criação dos DTO, estava havendo alguns erros e o IDE orientou a incluir um public static, 
que não necessariamente utilizei em outras API, porem funcionou normalmente.

Assim, não soube seguir a partir do GlobalExceptionHandler.
